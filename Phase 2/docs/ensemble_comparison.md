# Ridge＋随机森林：简单平均与约束 MAE stacking

作者：**yexueying70-cell**

更新：2026-10-07

[已运行 Notebook](../notebooks/ensemble_comparison.ipynb) 是本轮唯一的集成模型阅读入口。正文只比较两种方法；其他尝试及首版测试结果集中放在附表中。

## 两种保留方案

基础模型为前期保留的 `ridge_logx_a1000`（7项数值输入 log1p，alpha=1000）和 `rf_recent180`（森林训练订单按180天半衰期加权）。它们与原始 alpha=100 Ridge、未加近期权重森林不同。原四个单模型及其变体的三月结果在 Notebook 中注明配置。

**50/50简单平均：** `prediction = 0.5 × Ridge + 0.5 × Forest`，无需训练第二层权重。

**约束 MAE stacking：** 从历史时间 OOF 中拟合 `prediction = w × Ridge + (1-w) × Forest`，直接最小化绝对误差，要求 `0 ≤ w ≤ 1`，截距固定0。最终历史拟合得到 Ridge 约53.1%、森林约46.9%；这只是该次拟合的权重，重新训练时会重新学习。元模型使用全部符合时间条件的历史 OOF。

两个模型的误差相似时，学习权重不保证优于固定平均。凸组合也无法把预测扩展到两个基础预测的范围之外。

## 同期比较与结论

| 方案 | 主验证平均月度 MAE | 主验证平均月度 RMSE | 五月 MAE |
|---|---:|---:|---:|
| 改进 Ridge | 5.774 | 9.147 | 4.604 |
| 改进森林 | 5.747 | 9.157 | 4.755 |
| 50/50平均 | **5.717** | **9.109** | **4.574** |
| 约束 MAE stacking | 5.724 | 9.122 | 4.593 |

单位为天。主验证为2017年10月至2018年4月，共44,695笔订单；每个月等权，不能与合并所有订单后计算的 MAE 混称。五月6,726笔仅作敏感性检查，不用于重新选择参数。表中突出的是两个保留基础模型及其组合；全部四个单模型的同期结果见 Notebook，五月普通线性回归 MAE 为4.456天。

约束 stacking 比同期原 Ridge stacking 架构的5.803天有所改善，但相对较好的单模型森林仅改善约0.41%；固定平均还略好于学习权重，未体现额外复杂度的明确价值。四模型约束、中位数回归、近期窗口、30天间隔等尝试没有成为主方案，其摘要单独保留。

首版四模型 stacking 的三月 MAE 为6.558天，但已保存的最终测试 MAE 为4.916天，差于普通线性3.761天。这些是此前实验的历史记录，不是新模型的测试成绩。

## 时间边界与证据限制

- 2017年7月至2018年6月生成12个月的 OOF；7—9月预热，10月至次年4月为主验证，5月为敏感性检查。
- 各月基础模型训练只使用该月起点前已下单且已收货的订单。填补、编码和缩放在训练折内拟合。
- 元模型只使用更早月份的 OOF，且再次要求标签在当前起点前已可见。
- 评分标签统一限制为2018-07-01前可见。五月仍有0.341%的最终合格订单未收货；六月为27.444%，不作为评分月。六月已经可见的 OOF 标签可参与最终历史拟合。
- 最终基础模型使用82,258笔历史订单，元模型使用68,059笔 OOF。逐月重新训练是评价假设。

本轮是在看过首版测试结果之后形成的探索性开发；前期基础配置和保留结构也已经经过开发选择。历史验证不是新的无偏测试，完整配送样本筛选与标签成熟度仍有限制。公开复现只重现两个已保留方案，不重新评分七月起测试，也不重新搜索其他结构。

## 复现

从仓库根目录进入 `Phase 2`，使用 Python 3.12：

```bash
cd "Phase 2"
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-stacking.txt
.venv/bin/python scripts/reproduce_ensemble_comparison.py --csv-dir /path/to/Olist_CSV
```

可用 `--archive /path/to/IT5006_Project-Data.zip` 替代 CSV 参数。已有本地训练数据、模型或未完成运行时，按脚本提示显式增加 `--overwrite` 重跑。输入来自原课程七张表，地理处理使用审计后的筛查、去重邮编中位数。

```bash
.venv/bin/python scripts/verify_ensemble_comparison.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/run_notebook.py notebooks/ensemble_comparison.ipynb
```

Notebook 默认只读公开汇总，不要求旧实验 Notebook、旧版本目录或训练好的模型；保存的审计记录与当前现场核验明确区分。原始 CSV/ZIP、逐订单输入、OOF、预测及模型由 Git 忽略。

实现复用冻结的 `src/stacking_tuning.py`、`src/stacking_regression.py` 及现有基础模型模块；日常运行使用上面的公开复现入口。`outputs/historical_evidence.json` 记录历史附表来源与公开文件指纹。历史表不由本轮重新评分生成。
