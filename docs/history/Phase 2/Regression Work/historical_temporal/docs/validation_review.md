## 方法判断与限制

1. 时间顺序加收货可见性排除训练标签泄漏；但本任务条件是已完成且有商品记录订单。未完成/取消订单没有同类可观察答案，不能假装模型覆盖全部新订单风险。
2. 历史CV预测组受3月截止标签成熟筛选，最新折>60天样本为0；已明确报告这一偏差。3月独立验证等待到7月，以覆盖全部37笔可见长尾。最终测试仍受归档完成标签范围限制。
3. 16个输入属于下单信息，但原始承诺无修改历史、产品属性无版本、邮编中心是全归档静态代理；无法证明所有历史时刻完全不变，按显式假设使用。
4. 最初把日历与稀有类别一起编码导致未来月份映射到不恰当的历史稀有桶；已改为固定已知日历域。普通线性仍受到稀少月份影响，于开发阶段补充Ridge。Ridge的选择依据训练CV；这个迭代不是事先完全登记的实验。
5. OOF预测由相应较早模型产生；配置选择与这些CV折共用数据，并非嵌套CV。可用于训练组合器，不可把其分数当无偏最终效果；March是开发比较，锁定测试负责最终评价。
6. Ridge与森林各有优势，森林未胜过March线性；log目标未提升CV，不使用。未做统计显著性检验，微小的0.004天差异不解释为实际优势。
7. 长尾误差与系统性低估尚未解决。保存原始长尾不等于预测能处理长尾，不把总体MAE提升当服务承诺优化或因果业务收益。
